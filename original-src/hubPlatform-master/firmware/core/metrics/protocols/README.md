# Important
supervisor.proto and wire.proto files must be sync with [firmware-metrics](https://gitlab.nurd.com/ezlo/firmware-metrics)

From these files C++ code is generated by he protoc compiler.
It's done automatically, no need to generate anything manually.

### Requirement
- Install Protobuf

### To regenerate CPP protobuf

    cd hubPlatform/firmware/core/metrics/protocols
    protoc -I=. --cpp_out=. ./supervisor.proto
