# Watcher
The Watcher project aims to manage the services in the hub and the hub itself.

# Structure
Watcher is a management service built around the ubus messaging protocol, which receives service information from services, processes this information, and forwards this information to the metrics service to send it to cloud services when requested. For more information, you can check out the Watcher section on [confluence](https://confluence.mios.com/display/ELFD/Proactive+Reporting#ProactiveReporting-Watcher).
