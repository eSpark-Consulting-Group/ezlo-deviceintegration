### Coding style check/format script
Default folder for check/format is ** <project root>/firmware **
Run from *<project root>/misc/scripts* as ** ./code_style.py -h ** for help
Run from *<project root>/misc/scripts* as ** ./code_style.py --action=check ** for derfault folder check
Run from *<project root>/misc/scripts* as ** ./code_style.py --action=format ** for derfault folder format
